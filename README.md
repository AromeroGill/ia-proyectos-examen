# Proyectos IA - Examen Final

Tres proyectos que cubren los 7 ejercicios del curso de IA:

- **Proyecto A** — Asistente web (chat + Q&A) con Ollama y PHP. Cubre ejercicios 1, 2 y 3.
- **Proyecto B** — Corrector de correos con modelo personalizado. Cubre ejercicios 4 y 5.
- **Proyecto C** — RAG con stack PHP + Python. Cubre ejercicios 6 y 7.

## Requisitos

- XAMPP (Apache)
- Python 3.12+
- Ollama con modelo `llama3.1:8b`
