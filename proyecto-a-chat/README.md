# Proyecto A — Asistente web con IA local

Web que ofrece dos modos de interacción con un modelo de IA local:
- **Chat conversacional** con memoria.
- **Pregunta y respuesta** directa, sin memoria.

## Ejercicios del temario que cubre

- **Ejercicio 1** — Instalación y uso de Ollama con modelos locales.
- **Ejercicio 2** — MicroChatGPT con PHP.
- **Ejercicio 3** — Pregunta y respuesta.

## Cómo arrancar

1. Asegúrate de que Ollama está corriendo y de tener `llama3.1:8b` descargado.
2. Arranca Apache en XAMPP.
3. Abre: http://localhost/ia-proyectos/proyecto-a-chat/

## Configuración

Editar `config.php` para cambiar el modelo o la URL de Ollama.
